# Lab 6 – Strings in C++

## Overview
This lab focuses on understanding and implementing string operations in C++. Strings are used to store and manipulate text data.

## Objectives
- Understand the string data type.
- Perform basic string operations.
- Reverse a string.
- Count total characters.
- Convert strings into uppercase.
- Compare first and last characters.
- Concatenate two strings.

## Lab Tasks

### Task 1: Reverse a String
Take a string from the user and display it in reverse order.

### Task 2: Count Characters
Count the total number of characters using the `length()` function.

### Task 3: Convert to Uppercase
Convert all characters of a string into uppercase using `toupper()`.

### Task 4: Check First and Last Character
Check whether the first and last characters of a string are the same.

### Task 5: Concatenate Two Strings
Take two names from the user and combine them into one full name.
